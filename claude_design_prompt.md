Design a light, professional, premium design system for "CampaignIQ" — an AI-powered marketing campaign intelligence dashboard used by performance marketing agencies to analyze client ad-spend data and get AI-generated recommendations.

Product context:
- A data-dense analytics dashboard (KPI cards, charts, tables) combined with AI-generated narrative text (executive briefs, recommendations, chat responses)
- Used by agency account managers presenting to both internal analysts and external clients — needs to feel trustworthy and boardroom-appropriate, not "hackathon neon"
- Wide desktop layout, sidebar + tabbed main content

Aesthetic direction:
- Light theme — white/very light neutral backgrounds, NOT dark/black
- One confident primary accent color (indigo or deep blue), used sparingly for CTAs, active states, and key numbers — not everywhere
- Clean sans-serif typography, generous whitespace, restrained shadows instead of glows
- Should feel like Stripe, Linear, or Notion's dashboard polish — premium SaaS, not flashy

Please generate:
1. A color palette: background, surface/card, primary accent, secondary accent, success/warning/critical status colors (for "healthy/warning/critical" campaign badges), text (primary/secondary/muted), and border colors — both for normal state and hover/active states
2. A type scale: page title, section header, card label, card value/metric (large number), body text, small/caption text
3. Component specs for: KPI stat cards, an "AI insight" card (a highlighted box that contains AI-generated text with headers/bold/bullets), navbar/header bar, sidebar, tab navigation, buttons (primary/secondary/disabled), status badges (healthy/warning/critical pills), chat message bubbles (user vs AI), and a data table
4. A chart color sequence (6-8 colors) that works on a light background and stays distinguishable in both bar and line charts

Output as a reusable design system (colors as hex tokens, spacing scale, component previews) I can hand to a developer to implement as custom CSS in a Python Streamlit app.
